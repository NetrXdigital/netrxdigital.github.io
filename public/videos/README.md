# Homepage background video

Place the homepage hero video in this folder using this exact filename:

`hero-bg.mp4`

The video should be exported as H.264 MP4, muted/no-audio, and optimized for the web. Recommended settings:

- 1920x1080 maximum (1280x720 is often sufficient for a background)
- 24 or 30 fps
- H.264 video codec
- No audio track
- Fast Start / Web Optimized enabled
- Target size: approximately 5-12 MB

A 46 MB file will work, but it will make the first page load slow, especially on mobile. Compress it before replacing `hero-bg.mp4`. Keep the filename unchanged so no code changes are required.
